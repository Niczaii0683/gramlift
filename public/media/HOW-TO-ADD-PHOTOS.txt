HOW TO ADD PHOTOS TO GRAMLIFT
=============================

There is no upload button, and you do not need one.

This folder IS the upload. Drag a photo in here with the right filename
and it appears on the website. Replace the file with a different photo,
same name, and the website changes. You never open the code.

THREE STEPS, EVERY TIME
-----------------------
1. Rename your photo to one of the filenames below
2. Drag it into  Desktop/gramlift/public/media/
3. Open Terminal and run:
       cd ~/Desktop/gramlift
       git add .
       git commit -m "new photos"
       git push

Wait about two minutes, then hard refresh the site with Cmd+Shift+R.

Any slot with no file is skipped automatically. Nothing breaks while a
slot is empty, so you can fill them one at a time.

CHANGING THE SIZE OF ANY PHOTO SPACE
------------------------------------
Open  public/index.html  and press Cmd+F for       SIZE
There are eight of them. Each one sits right above the setting it
controls, and says what to change.

The shape of a photo frame is set by "aspect-ratio":
       4/3   wide            (1200 x 900)
       1/1   square          (1200 x 1200)
       16/9  very wide
       3/4   tall

So to make the hero square, find the SIZE note for HERO PHOTO and
change  aspect-ratio:4/3  to  aspect-ratio:1/1

The faces are set by one number instead:
       width:96px;height:96px       both numbers must match


EDITING THE WORDS
-----------------
Open  public/index.html  and press Cmd+F for  EDIT ZONE
Everything you would change day to day is in that block near the top:
prices, rotating captions, review quotes, the faces line, step text,
and the support email address.

To remove the little grey "Example" tag on a review card, find that
review's line in the REVIEWS list and change
       sample:true      to      sample:false
Do it on all three lines to clear all three tags.


FILE TIPS
---------
Use .jpg, not .png. Much smaller files.
The name must end in .jpg exactly. If Finder shows hero.jpeg, rename it
to hero.jpg or the site will not find it.
Keep each one under about 300 KB so the page loads fast.
Free photos cleared for commercial use: unsplash.com and pexels.com
Search terms that fit: "friends smartphone laughing", "content creator
filming", "young woman phone cafe", "phone screen hands"
