GramLift image slots
====================
Drop images into this folder using these exact filenames.
Any file that is not here is skipped automatically, nothing breaks.

ROTATING STRIP (beside the reviews, changes every 2.4 seconds)
  rotate-1.jpg   square, about 800 x 800
  rotate-2.jpg
  rotate-3.jpg
  rotate-4.jpg
  rotate-5.jpg
  Edit the caption under each one in the ROTATING list in index.html.
  Change ROTATE_SPEED there to make it faster or slower.

BEFORE / AFTER CARDS (static)
  result-1.jpg   landscape, about 800 x 600
  result-2.jpg
  result-3.jpg

REVIEW AVATARS (static)
  review-1.jpg   square, about 200 x 200
  review-2.jpg
  review-3.jpg

SUPPORT CARD
  founder.jpg    landscape, about 800 x 600

Tips
  Use .jpg, keep each file under about 300 KB so the page loads fast.
  Replacing a photo means saving the new one with the same filename.
  Nothing in the code changes when you swap a photo.
